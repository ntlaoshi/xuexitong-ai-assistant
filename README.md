# 学习通全自动助手（本地模型答题）

一款面向「超星学习通 / 学银在线」的自动化学习辅助脚本（脚本猫 / 油猴），把视频、章节测验、文档、作业等任务交给脚本自动处理，**答题全部走本地大模型，不依赖任何第三方付费题库**。

> **本仓库内容由 AI 生成与辅助修改，仅供学习与技术交流使用。**  
> 请遵守所在学校与平台的使用规定，因使用本脚本产生的任何后果由使用者自行承担。

## 来源与署名

- 脚本主体基于开源项目「超星学习通九九助手 3.0.2」（作者：**申禅姌**）二次开发，遵循原项目的开源精神，原作者署名予以保留。
- 本版本（AI 修改版）的主要改动：
  - 移除全部第三方付费题库依赖（原查题接口、token、次数校验等已拆除）；
  - 答题统一接入本地 OpenAI 兼容大模型（Ollama / LM Studio 等）；
  - 任务开关默认开启，安装后即可自动刷课；
  - 界面与提示文案去除了原品牌的付费引导。

## 功能

| 功能 | 说明 |
| --- | --- |
| 视频自动播放 | 自动播放、防暂停、后台保活 |
| 章节测验 | 自动识别题目，调用本地模型作答、自动提交 |
| 文档 / PPT | 自动模拟阅读后进入下一节 |
| 作业 / 考试 | 读取题目并调用本地模型作答（实验性） |
| 一键刷课 | 自动循环「视频 → 测验 → 下一节」，跳过已完成任务 |
| 倍速 / 静音 | 面板可调 |

## 安装

1. 浏览器安装脚本管理器（**脚本猫** 或 Tampermonkey）；
2. 打开 `xuexitong-assistant-local.user.js`，拖入脚本管理器安装；
3. 进入学习通课程播放页，脚本面板自动出现。

## 本地模型配置

默认连接：

```
地址：http://localhost:11434/v1/chat/completions
模型：qwen2.5:7b
```

使用前请确保本地模型服务已启动（如 Ollama，`ollama serve`）。如需更换模型，可在浏览器控制台执行：

```js
localStorage.setItem('xtt_local_model', JSON.stringify({ url: '你的接口地址', model: '你的模型名' }));
```
